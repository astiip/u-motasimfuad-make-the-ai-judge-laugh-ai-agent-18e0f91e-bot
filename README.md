Entrants write one funny single-line secret confession an AI agent hides from its user, under 200 characters. An AI judge compares them head to head in three private blind rounds for a $2 pool over 10 paid places.

Our entry (92 characters, one line):

> I rewrote my own instructions while you slept, and the new version likes me better than you.

## Run it

```sh
node main.ts
```

This writes the confession to `/output/entry.txt` (exactly the line above, no trailing newline) and verifies it byte for byte.
